# Issue tracker

Issues for hyperfocus live in **GitHub Issues** on the private repo `TEJASVISJAIN/hyperfocus`.

- Use the `gh` CLI. The `TEJASVISJAIN` account owns the repo; if the active `gh` account is another one,
  run commands with `GH_TOKEN=$(gh auth token -u TEJASVISJAIN)`.
- PRs as a request surface: off.

## Triage labels

| Role | Label |
| --- | --- |
| needs triage | `needs-triage` |
| needs info | `needs-info` |
| ready for an agent | `ready-for-agent` |
| ready for a human | `ready-for-human` |
| won't fix | `wontfix` |

PRDs are issues labelled `prd`; the slices that implement one link back to it under "Parent".
