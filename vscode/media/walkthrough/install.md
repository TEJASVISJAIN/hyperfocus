## Get hyperfocus

hyperfocus is a small command-line tool that wraps your coding agent (Claude Code, Codex CLI or
Gemini CLI). It needs Node.js 22 or later.

Install it once:

```
npm install -g @ddalus/hyperfocus
```

Or skip installing: the extension runs it with `npx @ddalus/hyperfocus` when it isn't on your PATH.
